# SkillSense: Tactile Myoelectric Prosthetic Hand with Dynamic Skill Transfer
# 智驭灵肢：具备动态技能迁移能力的触觉肌电假肢手

> **参赛项目**：中美青年创客大赛北京分赛区
>
> **项目团队**：北京邮电大学 × 伦敦玛丽女王大学 联合团队
>
> **核心技术**：TKE-BGC多模态仿生控制器 | 触觉共享控制 | DiffSR鲁棒肌电解码

## 📖 项目简介
本项目面向全球上肢截肢者**感知缺失、肌控负担重、动态技能难适**三大核心痛点，首创**健全人动态工具操作技能向截肢者精准迁移**的技术框架。通过融合触觉、动觉与肌电信号的TKE-BGC仿生控制器，实现了敲钉子、锯木头等高动态任务的稳定操作，将用户肌肉激活强度降低81.5%，连续使用时长从30分钟延长至2小时以上，为上肢截肢者重返工作岗位提供了核心技术支撑。

项目成果已发表于**Cyborg and Bionic Systems（SCI一区，IF=18.1）**，并与首都医科大学附属北京积水潭医院、上海傲意科技等达成临床与产业化合作。

## 🚀 核心技术突破
1.  **TKE-BGC多模态仿生控制器**：首次实现跨人群动态操作技能迁移，在刚性冲击场景下工具掉落率降低92%
2.  **触觉驱动人机共享控制**：0.1N级高精度力感知，实现类人化自主抓握力调节
3.  **DiffSR鲁棒肌电解码算法**：动态场景下意图识别准确率达90.6%，抗干扰能力提升40%

## 🛠️ 快速开始
### 1. 硬件组装
1.  下载`hardware/Assembly/`文件夹内的所有STL文件
2.  使用PLA材料3D打印所有部件
3.  按照装配说明文档组装机械结构与电子元件

### 2. 软件安装
1.  安装`CH340驱动.zip`中的串口驱动
2.  解压`舵机上位机.zip`，运行`ServoController.exe`
3.  连接假肢手USB接口，选择对应串口号并打开
4.  进行关节零位校准与力控参数调试

### 3. 技能迁移验证
1.  佩戴肌电传感器完成基础手势标定
2.  选择预设工具操作技能（敲钉子/锯木头/削皮）
3.  系统自动加载TKE-BGC控制模型，即可开始操作
